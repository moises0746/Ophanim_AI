# Desktop Application

This directory is reserved for the planned Tauri, React, TypeScript, and Vite control center.

Do not scaffold the application until Milestone 1 contracts for tasks, events, approvals, provider health, and emergency stop are stable enough to consume. See `docs/product/milestones.md`.

Future UI ownership includes the Home/Assistant surface and its state-driven animated Ophanim visualization. The visual is a semantic orchestration surface, not a static logo. Its implementation belongs under a future desktop Assistant UI module and must consume authoritative Assistant/Agent activity events from Ophanim Core.

S00-T02 reserves that ownership only. It does not add animation assets, voice processing, audio reactivity, an event transport, frontend state management, or runtime scaffolding. See `docs/product/ui-ux.md` for the reserved states, accessibility requirements, and activity-feed boundary.
