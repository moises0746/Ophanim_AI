## Scope Rule

The product vision is broader than the MVP. The first production vertical slice remains a text-operable, read-only Transaction Investigation Skill. Voice, broad enterprise integrations, infrastructure operations, content workflows, and approval-gated writes remain later product increments unless separately authorized.

Accepted architecture decisions under the [ADR index](../adr/README.md) govern these product requirements. Later contracts, implementation tasks, tests, and release evidence should cite the stable requirement and journey identifiers defined here.
