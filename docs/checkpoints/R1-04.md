# R1-04 Checkpoint — Core Persistence & SQLAlchemy Repositories

## Status

Complete. Next authorized task: **R1-05 / Authentication, Tenant/Workspace, and Device Identity**.

## Delivered

- **Database Engine & Session Management**:
  - Implemented `create_db_engine()`, `create_session_factory()`, `init_db()`, and `get_session()` transaction context manager in `ophanim/persistence/database.py`.
  - Configured transparent support for SQLite in-memory/file databases and PostgreSQL connections with unified SQLAlchemy 2.0 ORM patterns.
- **SQLAlchemy Declarative Models** (`ophanim/persistence/sql_models.py`):
  - `TaskRecord`: Stores task identifier, owner, workspace, title, objective, status, environment, risk level, privacy mode, priority, correlation ID, data scopes, and UTC timestamps.
  - `TaskStepRecord`: Stores task step identifier, owning task relation with cascade delete, objective, status, dependencies, and sequence.
  - `EventRecord`: Stores immutable `EventEnvelope` activity and assistant events with UTC timestamps, correlation/causation tracking, contextual references, and sanitized JSON payloads.
  - `PolicyDecisionRecord`: Stores policy evaluation records, rule IDs, effects, and obligations.
  - `ApprovalRecord` & `EvidenceRecord`: Stores approval requests and immutable cryptographic evidence records.
- **Persistent Repositories** (`ophanim/persistence/sql_repository.py`):
  - `SQLTaskRepository`: Save, get, list by owner and workspace, step synchronization (upsert/delete).
  - `SQLEventStore`: Append event envelopes, query events by task ID and correlation ID.
  - `SQLPolicyRepository`: Save and query policy decision records.
- **Integration Tests** (`services/ophanim-core/tests/test_sql_persistence.py`):
  - 8 comprehensive test cases verifying entity round-trips, step synchronization, event queries, policy persistence, timezone handling, and transactional rollback on exception.
