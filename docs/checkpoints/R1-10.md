## Delivered

- **Domain Scheduling Models** (`ophanim/domain/scheduling.py`):
  - `LeaseStatus` (`OFFERED`, `ACCEPTED`, `RUNNING`, `COMPLETED`, `FAILED`, `TIMED_OUT`, `CANCELLED`).
  - `DeviceCapabilityProfile`: Tracks enrolled node device capabilities, workspace bindings, heartbeat timestamps, and liveness.

- **Ports & Protocols** (`ophanim/ports/scheduler.py`):
  - `TaskLeaseRepositoryPort`: Storage interface for leases and active step locks.
  - `DeviceRegistryPort`: Device capability lookup and liveness tracking.
- **Adapters** (`ophanim/adapters/scheduler.py`):
  - `InMemoryTaskLeaseRepository`: Thread-safe lease storage.
  - `InMemoryDeviceRegistry`: Thread-safe capability registry with heartbeat age filtering.
- **Application Service** (`ophanim/application/scheduler_service.py`):
  - `DeviceSchedulerService`:
    - Matches task steps to online devices by workspace and tool capability.
    - Prevents duplicate active leases for the same task step.
    - Manages lease acceptance, execution reports, and cancellation.
    - Reclaims expired leases and marks them `TIMED_OUT`.
- **Unit & Integration Tests** (`services/ophanim-core/tests/test_scheduler.py`):
  - 5 test cases verifying lease offering, acceptance, completion, cancellation, fail-closed offline detection, and expired lease reclamation.
