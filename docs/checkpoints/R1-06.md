  - Implements provider fallback chains in case of inference failures.
  - `MockModelProviderAdapter`: Deterministic testing adapter supporting latency simulation, token usage estimation, and error injection.
- **Unit & Contract Tests** (`services/ophanim-core/tests/test_model_router.py`):
  - 5 test cases verifying local-only isolation, cloud routing for standard mode, capability rejection, provider fallback, and JSON structured response formatting.
