## Delivered

- **Identity Domain Models** (`ophanim/domain/identity.py` & `ophanim/domain/identifiers.py`):
  - Added domain identifiers: `TenantId`, `WorkspaceId`, `UserId`, `DeviceId`, `ApiKeyId`.
  - Implemented `Tenant`, `Workspace`, `User`, `Device`, `ApiKey`, and `IdentityPrincipal`.
  - Implemented `UserRole` (`admin`, `operator`, `auditor`, `member`), `DeviceType` (`desktop`, `node`, `cloud`), and `DeviceStatus` (`enrolled`, `active`, `offline`, `revoked`).
  - Implemented cryptographically secure API key generation (`generate_api_key`), constant-time HMAC/SHA-256 secret hashing (`hash_api_secret`, `verify_secret`), and wildcard scope matching.
- **SQLAlchemy Identity Persistence** (`ophanim/persistence/sql_models.py` & `sql_repository.py`):
  - `TenantRecord`, `WorkspaceRecord`, `UserRecord`, `DeviceRecord`, `ApiKeyRecord`.
  - `SQLIdentityRepository` implementing CRUD operations for tenants, workspaces, users, devices, and API keys.
- **Application Service** (`ophanim/application/identity_service.py`):
  - `IdentityService` providing tenant management, workspace provisioning, user registration with RBAC roles, device enrollment, device heartbeat tracking, device revocation, API key issuance, key revocation, and constant-time token authentication.
- **Integration Tests** (`services/ophanim-core/tests/test_identity.py`):
  - 8 test cases verifying tenant/workspace flows, user roles, device lifecycle, API token issuance and validation, token expiration, key revocation, device revocation cascading, and wildcard permissions.
