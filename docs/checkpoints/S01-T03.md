## Architecture Impact

Lifecycle rules remain framework-independent in the domain layer. The application service owns canonical process-local Task snapshots and imports no provider, API, database, browser, MCP, or vendor runtime.

## Security Impact

Reads and cancellation require exact owner/workspace scope. Missing and out-of-scope records share one sanitized error. Invalid operations fail closed. No credentials, external payloads, private source content, hidden reasoning, external calls, or production mutations are introduced.
