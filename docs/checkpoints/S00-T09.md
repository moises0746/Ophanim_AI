## Key Engineering Decisions

- The current runtime is not restructured in S00-T09. Future package migration requires a separately authorized task.
- Domain models remain framework-independent; Pydantic is for API/configuration/external DTO boundaries.
- PostgreSQL remains canonical; Redis is transient; SQLAlchemy is only a future authorized persistence choice.
- Celery remains the initial background-work direction but is not implemented.
- Application services enforce policy-before-tool and verification/evidence/audit ordering.
- Frontend and animation are projections of Core events, never policy or execution authority.
- Every external operation is typed, bounded, cancellable, timeout-controlled, classified, and observable.

## Prohibited Shortcuts

No giant autonomous agent, model-direct infrastructure execution, arbitrary SQL/shell/filesystem/browser/JavaScript/HTTP proxy, shared/global credentials, hard-coded secrets, route business logic, domain SQL/vendor imports, Redis canonical persistence, fake Activity Feed/Assistant progress, hidden chain-of-thought, silent catch-all success, unbounded retries, autonomous production writes, or product logic in vendor trees.
